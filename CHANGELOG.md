# Changelog

## 0.3.0

**Rename Clips** now applies one literal name to every matching clip —
no numbering. Type "Intro 128bpm Emin" and every clip in the selection
gets exactly that name.

## 0.2.0

Added **Rename Clips**: right-click a time selection, type a prefix,
every matching clip gets renamed to `Prefix 01`, `Prefix 02`, etc., in
track order. (Superseded by 0.3.0's simpler literal-name behavior.)

## 0.1.0

Initial release: **Clear Clip Names**. Right-click a time selection on
one or more tracks in Arrangement view to blank out the name of every
clip inside that range — a quick way to reset a messy project back to
Live's default clip labels.
